# визуализация графа зависимостей apt-пакетов

Инструмент читает CSV-конфигурацию, самостоятельно скачивает индекс
репозитория Ubuntu (`Packages.gz`), строит транзитивный граф зависимостей
заданного пакета, находит циклы, вычисляет порядок установки и
визуализирует граф (SVG через Graphviz + ASCII-дерево).

**Менеджеры пакетов (`apt`, `apt-cache`, `dpkg`) для получения зависимостей
не используются** — индекс репозитория парсится собственным кодом на
стандартной библиотеке Python.

---

## Зачем это нужно

Менеджер пакетов `apt` читает индекс репозитория и знает,
кто от кого зависит. Но он не показывает эту структуру наглядно. Инструмент
`depgraph` строит **карту зависимостей**: видно, какие пакеты нужны, в каком
порядке их ставить, где есть циклы (когда A нужен B, а B — A) и как выглядит
вся паутина целиком.

Полезно для:

- понимания, сколько «весит» пакет по зависимостям;
- поиска циклов и узких мест;
- обучения: как устроен `apt` внутри, как работают графовые алгоритмы.

---
Установка Graphviz:

- **Windows:** `winget install Graphviz.Graphviz` (или установщик с
  https://graphviz.org/download/ с галочкой «Add to PATH»).
- **Linux (Ubuntu/Debian):** `sudo apt install graphviz`.
- **macOS:** `brew install graphviz`.

После установки **перезапустить терминал**, проверить: `dot -V`.
